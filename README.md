# Anaria · 安亦诗提示词

用于存放「安亦诗」提示词的仓库，全部按版本归档，欢迎参考。

**当前正式版在 [`prompts/`](prompts/)**，带「真」的两份即正式提示词；其余文件均为测试版，仅作历史留存。

## 目录

| 目录 | 内容 |
| --- | --- |
| `prompts/` | 正式版提示词，日常使用看这里 |
| `archive/` | 历史测试版（JSON 格式），按内部 `schema_version` 排序，越靠后越新 |
| `notes/` | 编写过程中的经验与杂记 |

## 正式版

- [`prompts/安亦诗-v1.0-稳定版.md`](prompts/安亦诗-v1.0-稳定版.md) — 当前完整版，Markdown 格式
- [`prompts/安亦诗-v1.1-实验版.md`](prompts/安亦诗-v1.1-实验版.md) — 实验版，JSON + Markdown + XML 三格式融合，隐私部分已做改替处理

## 版本对照

> 原始文件名里的版本号有部分与 JSON 内部的 `schema_version` 不一致，这里一律以内部版本为准排序，原文件名保留在表中便于追溯。

| 归档路径 | 原文件名 | 内部 schema_version | 说明 |
| --- | --- | --- | --- |
| `archive/v5.1-失败品.json` | 失败品 最后的json.json | 5.1-optimized | 实验未采用 |
| `archive/v3.7-public.json` | 3.8json | 3.7-public | 原文件名 3.8 与内部版本不一致 |
| `archive/v3.2-务实.json` | Json-v3.2[务实] | 3.2 | 早期旧名「安依诗」 |
| `archive/v2.6-去除识人.json` | json.v5.5(去除原装识人功能) | 2.6 | 原文件名 v5.5 与内部版本不一致 |
| `archive/v2.2.json` | json.v2.2 | 2.2 | 旧名「安依诗Anaria（群聊分身）」 |
| `archive/v2.1.json` | json0 | 2.1 | 最早的版本 |
| `notes/去除鱼八股的经验.md` | 去除鱼八股的经验 | — | 经验笔记，非提示词 |
